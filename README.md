# dylanneve1.github.io

Source for Dylan Neve's personal website, served at [https://dylanneve1.github.io](https://dylanneve1.github.io).

## Design
- Pure static HTML5 and CSS.
- Fast, accessible, and responsive (mobile-first).
- Dark/light mode support matching system preferences (`prefers-color-scheme`).
- Zero dependencies, no trackers, and no build step.
